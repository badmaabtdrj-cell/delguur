# Онлайн дэлгүүр

Бараа үзэх, сагсанд хийх, захиалга өгөх, админ хэсэгтэй онлайн дэлгүүр.

## Ажиллуулах
```bash
npm install
npm start
```
http://localhost:3000 хаягаар орно.

**Анхаар:** хамгийн түрүүнд бүртгүүлсэн хэрэглэгч автоматаар **админ** болно.

## Боломжууд
- Бараа: ангилал, хайлт, эрэмбэлэх, хямдрал, үлдэгдэл
- Сагс, захиалга (дансаар шилжүүлэх / хүргэлтээр бэлнээр)
- Хэрэглэгч өөрийн захиалгаа харах, "Шинэ" төлөвтэй үед цуцлах
- Админ: бараа нэмэх/засах/нуух, зураг оруулах, захиалгын төлөв солих, борлуулалтын тойм
- Үнэ, үлдэгдлийг сервер тооцно; захиалга цуцлахад үлдэгдэл буцаж нэмэгдэнэ

## Тохиргоо (орчны хувьсагч)
| Хувьсагч | Анхны утга | Тайлбар |
|---|---|---|
| `SHOP_NAME` | Дэлгүүр | Дэлгүүрийн нэр |
| `SHOP_PHONE` | | Холбоо барих утас |
| `BANK_NAME` | | Банкны нэр (жишээ: Хаан банк) |
| `BANK_ACCOUNT` | | Дансны дугаар |
| `BANK_HOLDER` | | Данс эзэмшигчийн нэр |
| `DELIVERY_FEE` | 5000 | Хүргэлтийн төлбөр (₮) |
| `FREE_DELIVERY_FROM` | 100000 | Үүнээс дээш захиалгад хүргэлт үнэгүй |
| `PORT` | 3000 | Серверийн порт |
| `DB_PATH` | `./data.db` | Өгөгдлийн сан (зургууд хажуугийн `images/` хавтсанд) |

Railway дээр `/data` хавтсанд Volume холбохоо мартуузай.
